# Introduction to Machine Learning for Text Analysis with Python (2026)

Course materials for the 2026 edition of the GESIS Fall Seminar course "Introduction to Machine Learning for Text Analysis with Python", taught by Sjoerd Stolwijk and Rupert Kiddle.

**Dates:** 14–18 September 2026  
**Location:** GESIS Mannheim

Materials from previous years can be found in the [main repository](https://github.com/annekroon/gesis-machine-learning).

## Repository structure

```
exercises/       Jupyter notebooks for each day (exercises, solutions, supplementary materials)
slides/          Lecture slides (PDF; added per day during the course)
setup/           Setup guide for configuring your Python environment
```

## Getting started

Please consult the [setup guide](setup/setup_guide.md) to configure your Python environment and clone this repository before the course begins.
